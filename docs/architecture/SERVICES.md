# External Services

LifeOS will rely on various external services to enrich its data and capabilities.

## Current Services
- *(None currently integrated - using static data)*

## Planned Services
1. **Weather API:** (e.g., OpenWeatherMap) to adjust travel recommendations (e.g., "Leave earlier, it's raining").
2. **Transit API / Web-Scraping:** To get real-time bus status instead of static JSON files.
3. **Calendar API:** (Google Calendar / CalDAV) to automatically import `ClassBlock` and other events.
4. **AI/LLM Providers:** (Gemini) for natural language processing and complex decision making.
