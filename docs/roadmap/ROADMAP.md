# LifeOS Roadmap

This roadmap outlines the journey from AppHorarios to the full LifeOS platform.

## Phase 1: Foundation (AppHorarios) - *Current*
- Static bus schedules.
- Basic routing and recommendations.
- PWA setup.

## Phase 2: Dynamic Data & MVP (See `MVP.md`)
- Real-time or dynamic schedule updates.
- Basic user context (location).
- Integration with calendar.

## Phase 3: AI Integration & Automation
- Incorporating Gemini for smart recommendations.
- n8n workflows for background data syncing.

## Phase 4: Full LifeOS (See `FUTURE.md`)
- Task management, habits, memory.
- Event-driven micro-frontend architecture.
