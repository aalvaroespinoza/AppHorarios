# Core Principles

When building and expanding LifeOS, we adhere to the following principles:

## 1. Local and Private First
User data is highly personal. Whenever possible, data should be stored locally or in a private, self-hosted environment.

## 2. Modular Design
Every major capability (e.g., Transit Schedule, Task Management, Habit Tracking) should be an isolated module. They can share core types and UI components, but business logic must remain decoupled.

## 3. Proactive, Not Reactive
The system should present actionable recommendations (e.g., "Leave in 10 minutes to catch the 14:30 bus") rather than forcing the user to dig through raw data.

## 4. AI as an Enabler
Artificial Intelligence should act as a background orchestrator and an interface enhancement, not a gimmick. It should help process unstructured data and automate workflows.

## 5. Simplicity in UI
Despite the complex underlying architecture, the user interface must remain clean, accessible, and fast.
